# FinGuard AI — Privacy Policy

**Effective Date:** October 2026  
**Context:** Academic / Educational Demonstration  

## 1. Scope & Purpose
FinGuard AI is an educational transaction fraud-risk screening application built by university students in India for deep learning and machine learning coursework demonstration.

## 2. Data Handling Practices
- **No Cloud Storage:** FinGuard AI runs entirely locally. Transaction inputs entered into the screening form are evaluated in-memory and are never stored in an external database, tracker, or cloud telemetry service.
- **No Real Personal Identifiable Information (PII):** The application evaluates synthetic or publicly anonymized datasets. Users should not enter real credit card numbers, CVVs, bank credentials, or government IDs.
- **Local Logs:** Server logs generated by local development servers (`uvicorn`, `vite`) reside only on the user's local filesystem and can be cleared at any time.

## 3. Third-Party Integrations
FinGuard AI uses no third-party tracking cookies, analytics SDKs, advertising networks, or commercial payment gateways.
